# Working with Amazon EBS (Elastic Block Store)

**Amazon EBS (Elastic Block Store)** is a cloud-based block storage service provided by Amazon Web Services for use with its virtual servers (Amazon EC2 instances). It is like a virtual hard drive in the cloud. It lets you store data that needs to persist even when an EC2 instance is stopped or restarted.

### Amazon EBS Key Benefits

- **Scalability**  
  EBS allows you to quickly scale storage performance and capacity to support enterprise-grade applications without disrupting operations.

- **High performance**  
  EBS provides high availability and durability, including replication within Availability Zones and up to 99.999% durability with io2 Block Express volumes.

- **Optimize storage and cost**  
  You can choose different volume types to balance cost and performance, from low-cost general-purpose storage to high-IOPS, high-throughput options.

- **Security**  
  EBS encrypts data at rest and in transit while allowing you to control access and avoid managing your own encryption key infrastructure.

- **Simple data protection**  
  EBS Snapshots provide point-in-time backups that support disaster recovery, data migration, and compliance requirements.


  
### Key Features

- **Block storage**: Data is stored in fixed-size blocks, similar to a traditional SSD or HDD.  
- **Persistent storage**: Data remains intact independently of the lifecycle of the EC2 instance.  
- **High performance**: Designed for workloads like databases, file systems, and enterprise applications.  
- **Scalable**: You can increase storage size or performance as needed without downtime.  
- **Snapshots**: You can back up volumes to Amazon S3 via incremental snapshots.


Scale fast for your most demanding, high-performance workloads, including mission-critical applications such as SAP, Oracle, and Microsoft products.

High performance
Protect against failures with high availability, including replication within Availability Zone (AZs), and 99.999% durability with io2 Block Express volumes.

Optimize storage and cost
Select the storage that best fits your workload. Volumes range from cost-effective dollar-per-GB to high performance with the fastest IOPS and throughput.

Secure
Encrypt your block storage resources without needing to build, maintain, and secure your own key management infrastructure. Prevent unauthorized access to your data by restricting public access and configuring locks on data backups.

Simple data protection
Protect block storage data in the cloud, as well as on-premises block data using Amazon EBS Snapshots – a point-in-time copy that can be used to enable disaster recovery, migrate data across regions and accounts, and improve backup compliance. AWS further simplifies the lifecycle management of your snapshots through integration with Amazon Data Lifecycle Manager, which allows you to create policies so that you can automate multiple tasks including creation, deletion, retention, and sharing of snapshots.
